# The cast (`spells/pipeline/`)

The cast. `Spell` (`Spell.h`, `Spell.cpp`) from preparation and checks (`SpellCast`, `SpellChecks`, `SpellCheckTarget`, `SpellPower`, `SpellCooldown`) through targeting (`SpellTargeting`, `SpellTargetList`, `SpellAreaTargets`, `SpellTargetDistanceOrder.h`) and hit (`SpellHit`) to the effects (`SpellEffect*.cpp`, entered through `SpellEffectDispatch.cpp`) and the packets (`SpellPackets`). `UnitSpellBonus.cpp` holds `Unit`'s spell damage and healing bonus members. A spell-ID site here dispatches into `spells/handlers/`. The directory is on the `game` target's include path.
