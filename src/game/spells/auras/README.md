# The aura (`spells/auras/`)

The aura. `Aura` and `SpellAuraHolder` (`SpellAuras.h`, `SpellAuras.cpp`), the aura type handlers by family (`SpellAura*.cpp`), the aura definitions (`SpellAuraDefines.h`), `Unit`'s aura members (`UnitAura.cpp`), its proc handling (`UnitAuraProcHandler.cpp`) and the aura queries the code outside the seam asks (`AuraQueries.cpp`, declared in `spells/AuraQueries.h`, outside the seam). `CheckLayout` gates this directory, with `spells/AuraContainer.h`, as the `spells/aura` seam: an include into the seam from a file outside it, the spell peer's own files included, is listed per includer file and header and cannot grow. Include its headers by their path from `src/game`.
